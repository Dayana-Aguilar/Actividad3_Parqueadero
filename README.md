# Actividad 3 - Proyecto Parqueadero

## Descripción

Este proyecto corresponde a la Actividad 3 de la asignatura Programación Orientada por Objetos.

Se desarrolló un sistema de gestión de parqueadero en Java aplicando los conceptos de:

- Herencia
- Polimorfismo
- Sobreescritura de métodos
- Uso de colecciones (ArrayList)
- Manejo de fechas con LocalDateTime

## Funcionalidades

- Registro de entrada de vehículos.
- Registro de salida con cálculo automático del costo.
- Gestión de diferentes tipos de vehículos:
  - Automóvil
  - Motocicleta
  - Camión
- Cálculo de tarifa según tipo de vehículo.
- Consulta de vehículos actualmente en el parqueadero.
- Interfaz simple por consola.

## Estructura del Proyecto

El proyecto está organizado en los siguientes paquetes:

- `parqueadero.model` → Clases Vehiculo, Automovil, Motocicleta y Camion.
- `parqueadero.service` → Clase Parqueadero.
- `parqueadero.main` → Clase Main (ejecución del programa).

## Requisitos

- Java JDK 21
- IDE Eclipse
